# 汐听 TideListen 安卓版

手机和可直接安装 APK 的安卓车机分别使用 `phone` 与 `dashboard` 构建。两端共用 Midnight 默认主题、Media3 后台播放器和曲库。车机版的应用名为「汐听」，界面随车机窗口尺寸调整，可在支持分屏的系统中与其他应用并排显示。包名带 `.car`。最低系统为 Android 6.0，界面使用设备的 Android System WebView。

## 开始试听

1. 手机首页顶部可按歌曲或歌手搜索。在线歌单每行两张，旁边可切换排行榜；底部导航为「首页」「我的列表」「设置」。车机提供「搜索」「在线歌单」「排行榜」「我的列表」「设置」五个标签，横屏时在左侧切换，竖向分屏时在底部切换。车机在线歌单在横屏时按窗口宽度排列，竖向分屏时每行两张。重新打开车机会回到上次浏览的页面。可浏览内置 Online Metadata 提供的酷狗音乐、酷我音乐、网易音乐、企鹅音乐和咪咕音乐公开歌单和排行榜。选择来源、打开歌单并浏览歌曲，或者把歌单收藏到「我的列表」。
2. 在「设置 → 音源 → 导入音源」可选择洛雪自定义 JS 文件，也可从链接导入。通过「上移」「下移」调整已启用音源的优先级。播放器先匹配平台和所选音质，再从第一优先级开始逐个尝试。一旦打开可播放的音频，就停止尝试。首选音质没有可用结果时再降级，已失败的音源会在本次请求中跳过。链接导入后可从原链接更新。
3. 在「设置 → WebDAV → 配置」填写桌面版使用的服务器地址加同步路径，指向包含 `list/` 的目录。使用支持 WebDAV 读写的账号，新建、改名、收藏和移除歌曲等操作会自动同步到同一份歌单。网络异常时修改保存在当前设备，重新打开应用或恢复网络后会重试。只读账号可浏览远端歌单，尚未提交的修改会显示为待同步。
4. 「我的列表」中显示「我喜欢」和自建歌单。试听列表默认隐藏，可在设置中开启。可从播放条点爱心收藏，点歌曲标题或封面打开播放界面。此前版本的安卓在线曲库和收藏会在升级时导入相应列表。本地音频只在选中文件的设备上播放。
5. 完整播放界面使用内置 Online Metadata 获取在线歌曲的同步歌词。手机在封面下方显示歌词，车机横屏将封面和控制放在左侧，歌词放在右侧。
6. 车机播放条额外提供播放模式按钮，默认在前台播放时保持亮屏。可在「设置 → 播放与显示」更改行为。

内置的在线搜索、歌单、排行榜、封面和歌词模块取自官方 [Online Metadata v0.4.9](https://github.com/any-listen/any-listen-extension-online-metadata/tree/v0.4.9)。如需重新生成 Android 使用的子集，可在该版本源码安装 `he@1.2.0` 后，运行 `bash tools/bundle-online-metadata.sh <扩展源码目录> <esbuild的绝对路径>`。随包附有 Online Metadata 与 he 的许可证。

在线资源收藏为可更新的在线列表。旧收藏可从在线资源详情选择「关联已有列表」，也可在「编辑列表」手动填写来源。歌单和歌曲都可通过「排序」拖动手柄。选择汐听同步服务时，在设置中使用服务地址和一次性配对码连接。详见[配对、WebDAV 迁移及部署说明](../../sync-server/README.md)。

## 构建

准备 JDK 17、Android SDK Platform 35 和 Build Tools 35。在本目录执行：

```sh
./gradlew assemblePhoneDebug assembleDashboardDebug lintPhoneDebug lintDashboardDebug
```

Windows 可使用 `gradlew.bat`。APK 分别生成在 `build/outputs/apk/phone/debug/` 和 `build/outputs/apk/dashboard/debug/`。这些构建使用本机 Android 调试签名。

## 应用内更新

从 0.12.0 或更早版本升级，请手动覆盖安装一次。0.12.1 起手机使用 Android、车机使用 Android-Car 作为版本标识，在「设置 → 关于」可检查对应版本的更新。「测试版」默认不勾选，只接收正式版。勾选后也会检查 Beta 版本，取消勾选后不会降级已安装的版本。手机和车机使用各自的 APK，系统会验证同包名应用的签名。发布时分别构建 `assemblePhoneRelease`、`assembleDashboardRelease`，使用上一版对应的签名密钥为 Release APK 签名，并上传到同一 GitHub Release。安装包按主 README 的命名规则发布。

应用内更新在系统安装成功、取消或拒绝安装权限后自动清理私有缓存中的 APK。升级后也会清理旧版本遗留的更新包。浏览器下载目录中的手动安装包由用户管理。

首次为已配对的账号开启「同步音源」时，有服务器音源需要导入会显示审核。确认后，同一配对下的音源变更自动同步，覆盖安装或重新开启开关会沿用确认结果。断开配对后，新配对独立确认。同步时只保存脚本、启用状态和顺序。播放时按优先级尝试音源，初始化失败会继续尝试下一项。要查看某个脚本的初始化结果，请在「设置 → 音源」里点击该音源的「测试音源」。
